# Как мне собрать SmartKitchen и получить BIN для OTA

Инструкция для твоего компьютера и текущей ESP32 с flash 4 MB. Проверенная версия проекта — **2.1.0**. Для обычного обновления через браузер плату к USB подключать не нужно: сначала собираешь файл на компьютере, затем выбираешь его в веб-пульте.

## 1. Открыть правильную папку

Рабочая папка:

```text
C:\Users\toose\Documents\GitHub\SmartKitchen
```

Открой **SmartKitchen.ino** в Arduino IDE 2.x. Папка должна называться **SmartKitchen**, как и основной скетч. Все файлы `.h` и `logic_tests.cpp` должны оставаться рядом с ним. Отдельные заголовки компилировать не нужно.

Не открывай исходники из `backup-private`: это прежние версии. Если скачал проект ZIP-архивом, сначала распакуй его; при необходимости переименуй папку `SmartKitchen-main` в `SmartKitchen`.

## 2. Один раз установить поддержку ESP32

1. В Arduino IDE открой **File → Preferences** / **Datei → Einstellungen**.
2. В поле **Additional Boards Manager URLs** добавь отдельной строкой:

   ```text
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

3. Открой **Boards Manager** / **Boardverwalter**, найди **esp32 by Espressif Systems**.
4. Выбери версию **3.3.5** и установи её. Если она уже установлена — повторять не нужно.

Не выбирай «самую новую» версию автоматически: для этого проекта проверена именно 3.3.5. Порядок установки поддержки платы описан в [официальной инструкции Espressif](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html).

## 3. Один раз установить библиотеки

Открой **Library Manager** / **Bibliotheksverwalter**. Найди библиотеки по названиям и выбери указанные версии:

| Библиотека | Проверенная версия |
|---|---|
| DHT sensor library — Adafruit | 1.4.7 |
| Adafruit ILI9341 | 1.6.3 |
| Adafruit GFX Library | 1.12.6 |
| Adafruit BusIO | 1.17.4 |
| Adafruit Unified Sensor | 1.1.15 |
| UniversalTelegramBot — Brian Lough | 1.3.0 |
| ArduinoJson — Benoit Blanchon | **6.21.5** |

Если IDE предлагает установить зависимости, согласись, а затем проверь версии по таблице. В частности, UniversalTelegramBot может предложить более новую ArduinoJson: для нашей сборки выбери **6.21.5**, а не 7.x. `Arduino_JSON` — другая библиотека и не заменяет `ArduinoJson`.

WiFi, WebServer, Preferences, HTTPClient, ESPmDNS и Update уже входят в пакет ESP32; отдельно устанавливать их не нужно.

Ранее я собирал проект с библиотеками из отдельной рабочей папки Codex. Обычная Arduino IDE не обязана видеть эту папку, поэтому установи библиотеки через её менеджер, даже если готовый BIN уже успешно работает на плате.

## 4. Выбрать плату и параметры

В меню **Tools** / **Werkzeuge** выбери **ESP32 Arduino → ESP32 Dev Module**.

| Параметр | Значение |
|---|---|
| Board | ESP32 Dev Module |
| CPU Frequency | 240MHz (WiFi/BT) |
| Flash Size | 4MB (32Mb) |
| Partition Scheme | **Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)** |
| Flash Mode | QIO |
| Flash Frequency | 80MHz |
| PSRAM | Disabled |
| Core Debug Level | None |
| Erase All Flash Before Sketch Upload, если есть | Disabled |

Это соответствует стандартному профилю `esp32:esp32:esp32` проверенной сборки core 3.3.5. Остальные пункты оставь стандартными.

Для веб-OTA сохраняй **тот же Partition Scheme**. Не выбирай Huge APP, No OTA, No FS или другую таблицу разделов: обычное OTA не меняет таблицу разделов на устройстве. Фактический предел текущего раздела приложения — **1 310 720 байт**.

Для получения BIN порт COM выбирать не обязательно. COM4 нужен только при реальной загрузке по USB; после переподключения номер порта может измениться.

## 5. Проверить настройки сети

Для обновления уже работающего устройства через OTA **не нужно заново вводить Wi-Fi и Telegram в исходники**: они хранятся на устройстве в NVS. Там же сохраняются яркость и базы MQ.

`secrets.h` необязателен. Если его нет, проект собирается с пустой начальной сетью; при первом запуске нового устройства можно подключиться к резервной сети и настроить домашний Wi-Fi через пульт.

Если хочешь задать начальную сеть в исходниках, скопируй `secrets.example.h` в `secrets.h` и заполни:

```cpp
#pragma once
#define INITIAL_WIFI_SSID "ИМЯ_МОЕЙ_СЕТИ"
#define INITIAL_WIFI_PASSWORD "ПАРОЛЬ_МОЕЙ_СЕТИ"
```

Токен Telegram сюда добавлять не нужно — он задаётся в веб-пульте. `secrets.h` исключён из Git. BIN, собранный с таким файлом, содержит начальный пароль сети, поэтому не публикуй его.

## 6. Проверить компиляцию

Нажми кнопку **✓ Verify** / **Überprüfen**. Не кнопку со стрелкой загрузки.

Дождись окончания. Первая сборка может быть долгой: собираются зависимости ESP32. В конце должны быть строки о размере программы и RAM и не должно быть красного `Compilation error` / `exit status 1`.

Для переданного выпуска 2.1.0 результат был:

```text
Sketch uses 1237919 bytes (94%) of program storage space.
Maximum is 1310720 bytes.
Global variables use 53008 bytes (16%) of dynamic memory.
```

Это ориентир: после изменений кода или настроек размер может отличаться. Не меняй разделы ради устранения переполнения — текущий OTA-предел остаётся прежним.

## 7. Получить BIN

1. Выбери **Sketch → Export Compiled Binary** / **Sketch → Kompilierte Binärdatei exportieren**. Обычно сочетание клавиш — **Ctrl + Alt + S**.
2. Дождись успешного завершения: экспорт может ещё раз запустить сборку.
3. Выбери **Sketch → Show Sketch Folder** / **Sketch-Ordner anzeigen**.
4. В Arduino IDE 2.x ищи результат в подпапке:

   ```text
   C:\Users\toose\Documents\GitHub\SmartKitchen\build\esp32.esp32.esp32\
   ```

Для установленного пакета ESP32 3.3.5 это ожидаемое место экспорта. Если IDE сохранила файлы иначе, ищи `SmartKitchen.ino.bin` внутри открытой папки скетча и проверь время изменения. Обычная кнопка ✓ не гарантирует появления нового BIN в этой папке — для этого нужен экспорт. Общий механизм экспорта описан в [документации Arduino](https://docs.arduino.cc/arduino-cli/platform-specification/#recipes-to-export-compiled-binary).

**Для веб-OTA бери только `SmartKitchen.ino.bin`.**

| Файл | Через веб-OTA |
|---|---|
| `SmartKitchen.ino.bin` | **Да — это приложение** |
| `SmartKitchen.ino.bootloader.bin` | Нет |
| `SmartKitchen.ino.partitions.bin` | Нет |
| `SmartKitchen.ino.merged.bin`, `full.bin`, `with_bootloader.bin` | Нет |
| `boot_app0.bin` | Нет |

Переименование файла не меняет его содержимое. Можно переименовать готовое приложение в `SmartKitchen-v2.1.1-OTA.bin`, но нельзя переименовать merged/full в приложение и загрузить его через OTA.

Для ориентира: наш переданный `SmartKitchen-v2.1.0-OTA.bin` имеет размер **1 238 064 байта**. Размер BIN немного отличается от строки `Sketch uses` — это нормально. После собственной сборки хеш и размер не обязаны совпадать с переданным файлом.

## 8. Обновить кухню через браузер

1. Телефон или компьютер должен быть в той же домашней сети, что ESP32.
2. Открой [http://smartkitchen.local](http://smartkitchen.local) или IP, показанный внизу экрана. Ранее это был [192.168.0.215](http://192.168.0.215); роутер может выдать другой адрес.
3. Открой **«Обновление прошивки»**.
4. Выбери только что экспортированный **SmartKitchen.ino.bin** и отметь подтверждение совместимости.
5. Нажми загрузку и дождись перезапуска. В это время оставь питание включённым.
6. Проверь версию в веб-пульте или внизу TFT и работу датчиков.

При активной тревоге прошивка отклонит OTA. Сначала проверь реальную причину тревоги и состояние датчиков. Обычное OTA сохраняет настройки в NVS.

Если меняешь код для нового выпуска, перед сборкой удобно изменить строку `VERSION` в `SmartKitchen.ino`, например с `2.1.0` на `2.1.1`: после обновления будет видно, что загружен новый код. Метку совместимости `SmartKitchen:ESP32:layout-v2` для обычных изменений этого устройства не меняй.

## Если появилась ошибка

| Сообщение или ситуация | Что проверить |
|---|---|
| `DHT.h`, `Adafruit_ILI9341.h`, `UniversalTelegramBot.h` не найдены | Установлены ли соответствующие библиотеки в менеджере именно этой IDE |
| `ArduinoJson.h` не найден / ошибки типов ArduinoJson | Нужна ArduinoJson 6.21.5; Arduino_JSON её не заменяет |
| Ошибки `ledcAttachChannel` | Выбраны ли ESP32 Dev Module и пакет esp32 3.3.5; код рассчитан на API 3.x |
| Программа не помещается | Стандартный раздел вмещает 1 310 720 байт. Проверь версии библиотек и размер своих изменений; не переключай таблицу разделов для обхода ошибки OTA |
| Не удаётся скопировать `partitions.csv` при экспорте | Создай папку `build\esp32.esp32.esp32` внутри проекта и повтори экспорт. Такое поведение встретилось при подготовке проекта на этом компьютере |
| В папке лежит старый BIN | Запусти Export Compiled Binary и проверь время изменения файла |
| OTA пишет `Wrong image` | Выбран чужой проект, полный образ или файл без метки совместимости SmartKitchen |
| OTA отклонено из-за alarm | Проверь тревогу и подключение датчиков |
| Нужна обычная прошивка по USB | Выбери реальный COM-порт, при проблемах скорости установи Upload Speed 115200. Для текущего рабочего устройства используй веб-OTA, если нет необходимости в восстановлении |

При ошибке сохрани полный текст вывода IDE, начиная с первой ошибки. Повторно прошивать устройство или стирать flash для исправления ошибки компиляции не нужно.

## Короткая памятка на будущее

**Открыть SmartKitchen.ino → ESP32 Dev Module / core 3.3.5 → стандартные разделы 4 MB → Export Compiled Binary → взять SmartKitchen.ino.bin → загрузить в веб-пульте.**
